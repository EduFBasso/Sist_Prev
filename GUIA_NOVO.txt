📂 ESTRUTURA DE PASTAS:

   entrada/         → Coloque os PDFs do CNIS aqui
   saida/           → CSVs organizados por cliente (subpastas automáticas)
   info/            → Documentação do sistema


═══════════════════════════════════════════════════════════════════════
🔄 PASSO A PASSO
═══════════════════════════════════════════════════════════════════════


1️⃣  EXTRAIR DADOS DO PDF:

    a) Coloque o PDF do CNIS na pasta entrada/
    
    b) Execute o extrator Python:
    
       • Processar TODOS os PDFs:
         python converter_extrato_inss.py
       
       • Processar UM PDF específico:
         python converter_extrato_inss.py entrada/nome_arquivo.pdf
    
    c) O sistema cria automaticamente:
       saida/NOME_DO_CLIENTE/
          ├── extrato_TIMESTAMP_dados_cliente.csv
          ├── extrato_TIMESTAMP_vinculos_estruturado.csv
          ├── extrato_TIMESTAMP_remuneracoes.csv
          └── extrato_TIMESTAMP_validacao.txt


2️⃣  IMPORTAR NO VBA (Excel):

    a) Abra o arquivo: erp_prev.xlsm
    
    b) Execute a macro (Alt + F11 ou Alt + F8):
       
       ImportarCNIS_Automatico
    
    c) Selecione QUALQUER arquivo CSV da pasta do cliente
       (ex: saida/JOAO_CARLOS/extrato_20260112_160209_dados_cliente.csv)
    
    d) O sistema importa AUTOMATICAMENTE:
       ✓ Dados do cliente (NIT, CPF, Nome, Data Nasc)
       ✓ Vínculos (empresas, datas, tipos)
       ✓ Remunerações (salários por competência)


3️⃣  BUSCAR E SIMULAR:

    a) Abra o formulário de busca
    
    b) Digite o nome do cliente
    
    c) Dê duplo clique no resultado → abre cadastro
    
    d) Clique em "Simular" → abre simulações
    
    e) Clique em "Calcular" → análise automática das 5 regras
    
    f) Resultado mostra:
       ✓ Melhor regra identificada
       ✓ 3 cenários (pessimista, realista, otimista)
       ✓ Tempo de contribuição necessário

🗑️  LIMPEZA DE ARQUIVOS ANTIGOS
═══════════════════════════════════════════════════════════════════════

Para limpar arquivos antigos e manter apenas os mais recentes:

   • Windows (PowerShell):
     Get-ChildItem saida -Recurse *.csv | Remove-Item
   
   • macOS/Linux:
     find saida -name "*.csv" -type f -delete
